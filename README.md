A modern and responsive personal portfolio website developed using HTML5 and advanced CSS3 techniques. The project demonstrates responsive web design through CSS Grid, Flexbox, and mobile-first media queries. Custom CSS variables provide consistent colors, typography, spacing, and theme management throughout the website. A light and dark mode design improves usability and personalization. Interactive hover effects, smooth transitions, and responsive navigation create a polished user experience across mobile phones, tablets, and desktop screens. The website builds upon semantic HTML foundations and emphasizes clean styling, reusable CSS, maintainable code, and accessibility while showcasing personal skills, projects, and contact information.
